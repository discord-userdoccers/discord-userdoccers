# Content Inventory

Content inventory is a feature that allows users to view recent activities done by other users.

### Content Inventory Entry Object

###### Content Inventory Entry Signature

| Field        | Type                                                                         | Description                                                                      |
| ------------ | ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| id           | string                                                                       | The ID of the content inventory entry                                            |
| author_id    | snowflake                                                                    | The ID of the content inventory entry author                                     |
| author_type  | integer                                                                      | The [type of the content inventory entry author](#content-inventory-author-type) |
| content_type | integer                                                                      | The [type of the content inventory entry](#content-inventory-entry-type)         |
| traits       | array[[content inventory trait](#content-inventory-trait-structure) object]  | The traits of the content inventory entry                                        |
| extra        | [content inventory metadata](#content-inventory-metadata-object) object      | The content inventory entry metadata                                             |
| original_id? | snowflake                                                                    | Unknown                                                                          |
| participants | array[snowflake]                                                             | The IDs of the participants in the content inventory entry                       |
| expires_at?  | ISO8601 timestamp                                                            | When the content inventory expires                                               |
| ended_at?    | ISO8601 timestamp                                                            | When the content inventory ends                                                  |
| started_at?  | ISO8601 timestamp                                                            | When the content inventory starts                                                |
| signature    | [content inventory signature](#content-inventory-signature-structure) object | The content inventory entry signature                                            |

## Endpoints

<RouteHeader method="GET" url="/content-inventory/users/@me">
  Get Content Inventory
</RouteHeader>

Returns the content inventory feed.

###### Query String Params

| Field             | Type    | Description                                                           |
| ----------------- | ------- | --------------------------------------------------------------------- |
| refresh_token?    | string  | The refresh token                                                     |
| for_game_profile? | boolean | Whether the request is for game profile                               |
| feature?          | string  | The [feature with content inventory](#content-inventory-feature-type) |

###### Content Inventory Feature Type

| Value           | Description     |
| --------------- | --------------- |
| inbox           | Inbox           |
| game_profile    | Game profile    |
| recent_activity | Recent activity |
| overlay_invites | Overlay invites |
| admin           | Admin           |

###### Response Body

| Field                         | Type                                                                                      | Description                                                  |
| ----------------------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| request_id                    | string                                                                                    | The ID of the request                                        |
| entries                       | array[[ranked content inventory entry](#ranked-content-inventory-entry-structure) object] | The entries                                                  |
| unranked_game_entries         | array[[ranked content inventory entry](#ranked-content-inventory-entry-structure) object] | The unranked game entries                                    |
| entries_hash                  | integer                                                                                   | Unknown                                                      |
| expired_at?                   | ?ISO8601 timestamp                                                                        | When the feed expires                                        |
| refresh_stale_inbox_after_ms? | ?integer                                                                                  | Duration (in milliseconds) after which feed can be refetched |
| refresh_token?                | ?string                                                                                   | The refresh token                                            |
| wait_ms_until_next_fetch?     | ?integer                                                                                  | Duration (in milliseconds) until next fetch can be made      |

###### Ranked Content Inventory Entry Structure

| Field   | Type                                                              | Description |
| ------- | ----------------------------------------------------------------- | ----------- |
| content | [content inventory entry](#content-inventory-entry-object) object | The content |
| rank    | integer                                                           | The rank    |

<RouteHeader method="GET" url="/content-inventory/users/{user.id}/outbox">
  Get User Content Inventory Outbox
</RouteHeader>

Returns the user's content inventory outbox entries.

###### Response Body

| Field   | Type                                                                     | Description |
| ------- | ------------------------------------------------------------------------ | ----------- |
| entries | array[[content inventory entry](#content-inventory-entry-object) object] | The entries |

<RouteHeader method="DELETE" url="/content-inventory/users/@me/outbox/entries/id/{content_inventory_entry.id}/history">
  Delete Content Inventory Entry
</RouteHeader>

Deletes the content inventory entry. Returns a 204 empty response.
                
<RouteHeader method="POST" url="/content-inventory/users/@me/spotify">
  Create Content Inventory Spotify Entry
</RouteHeader>

Creetes a listening content inventory entry. Returns a 204 empty response on success.

###### JSON Params

| Field         | Type                                                    | Description                                   |
| ------------- | ------------------------------------------------------- | --------------------------------------------- |
| connection_id | string                                                  | The ID of the connection (max 512 characters) |
| tracks        | array[[spotify track](#spotify-track-structure) object] | The tracks (1-8)                              |

###### Spotify Track Structure

| Field  | Type                                                         | Description                                                       |
| ------ | ------------------------------------------------------------ | ----------------------------------------------------------------- |
| id     | string                                                       | The ID of the track (max 64 characters)                           |
| name   | string                                                       | The name of the track (max 1024 characters)                       |
| type   | string                                                       | The [type of the resource](#spotify-resource-type) (only `track`) |
| album? | [spotify track album](#spotify-track-album-structure) object | The album of the track                                            |

###### Spotify Track Album Structure

| Field | Type                                                                     | Description                                                                 |
| ----- | ------------------------------------------------------------------------ | --------------------------------------------------------------------------- |
| id    | string                                                                   | The ID of the album (max 64 characters)                                     |
| name  | string                                                                   | The name of the album (max 1024 characters)                                 |
| image | [spotify track album image](#spotify-track-album-image-structure) object | The image of the album                                                      |
| type  | string                                                                   | The [type of the resource](#spotify-resource-type) (only `album` or `show`) |

###### Spotify Track Album Image

| Field   | Type    | Description                         |
| ------- | ------- | ----------------------------------- |
| url     | string  | The image URL (max 1024 characters) |
| width?  | integer | The width of the image (16-8192)    |
| height? | integer | The height of the imgae (16-8192)   |

###### Spotify Resource Type

| Value    | Description            |
| -------- | ---------------------- |
| track    | Resource is a track    |
| artist   | Resource is an artist  |
| album    | Resource is an album   |
| playlist | Resource is a playlist |
| episode  | Resource is an episode |
| show     | Resource is a show     |
